# Conventions

## Naming

- Components: PascalCase
- Hooks: useSomething
- Files: kebab-case

---

## Commits

```
feat(scope): message
fix(scope): message
```

---

## Rules

- No API calls in components
- Use hooks
- Keep logic separated
- Validate API with Zod

---

## Styling

- Tailwind for layout
- MUI for components
