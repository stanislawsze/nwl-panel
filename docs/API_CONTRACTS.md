# API Contracts

The panel treats the Laravel API response shape as a runtime contract.

## Source of Truth

- Backend routes live in `nwl-api/routes/api.php` and `nwl-api/routes/api/v1/**`.
- Backend resources live in `nwl-api/app/Http/Resources/**`.
- Scramble exports OpenAPI to `nwl-api/api.json` when generated by the API project.
- Frontend endpoint paths are centralized in `src/shared/api/endpoints.ts`.
- Frontend response contracts are Zod schemas in `src/types.ts`.

## Flow

```text
Component -> React Query hook -> api client -> endpoint registry -> Zod schema -> Laravel API
```

## Drift Checks

Use these commands before pushing contract changes:

```bash
npm test
npm run test:e2e
```

`src/types.test.ts` contains representative backend resource payloads. When a backend resource changes, update that test and the matching Zod schema in the same frontend change.

`src/shared/api/endpoints.test.ts` protects the route strings used by the Axios client. When a Laravel route path changes, update `endpoints.ts` first and let the API client keep using the named endpoint.

## Diagnosing Zod Failures

The API client wraps response parse failures in an `ApiError` with:

- `message`: includes the endpoint path
- `details.endpoint`: the endpoint path
- `details.issues`: the Zod issues array

This means a frontend error like `The API response for /me did not match...` points directly to the route/resource pair to inspect in the API repo.
